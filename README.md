# Vionix Website

A multi-page, mobile-first static website for Vionix. Built with semantic HTML5, CSS3, inline SVG and vanilla JavaScript.

## Publish on GitHub Pages

Upload the contents of this folder to the root of the repository used for the Vionix project site. Keep `index.html` at the top level. GitHub Pages will publish the static files directly.

Current canonical/base URL: `https://vionixagency.github.io/vionix/`

If a custom domain is added later, update the canonical/base URLs in the generated pages, `robots.txt`, and `sitemap.xml`, and follow GitHub Pages custom-domain settings.

## Included

- Home, Services and 22 dedicated service pages
- Packages, Work, About, Blog and 3 editorial posts
- Contact + Free Growth Audit form
- Responsive navigation with dark Services mega-menu
- Interactive problem selector
- Inline SVG diagrams and illustrative charts
- Motion system with reduced-motion support and pause control
- Canonicals, metadata, sitemap, robots.txt and JSON-LD
- Custom 404 page

## Important notes

- Concept projects are explicitly labelled and do not claim client results.
- Illustrative numbers and charts are explicitly labelled as examples.
- The form uses `mailto:` because GitHub Pages is static. A form backend can be connected later without redesigning the form UI.
- Replace the founder portrait placeholder with the approved founder photo at `assets/images/founder.jpg` when available, then update the related `<img>` markup/alt text.
- Prices are planning starting points and should be finalized commercially after scope and market validation.

## SEO posture

The site structure follows current Google Search Essentials principles: crawlable internal links, descriptive titles/headings, unique page content, canonical URLs, structured data where useful, accessible text alternatives and an emphasis on people-first content. Ranking position is not guaranteed by technical implementation alone.
